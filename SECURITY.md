## Reporting a Vulnerability

We take the security of `docgen-cli` very seriously. If you believe you have found a security vulnerability in `docgen-cli`, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email or contact the maintainer at:
   - https://github.com/0xkaizoku/docgen-cli/security/advisories
3. Include details of the vulnerability, steps to reproduce, and any proof-of-concept.

We will acknowledge receipt within 48 hours and work with you to resolve the issue promptly before public disclosure.
